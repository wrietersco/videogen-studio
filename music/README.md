# Music library

Drop royalty-free MP3s here, organized by mood folder:

```
music/
  upbeat/     *.mp3
  cinematic/  *.mp3
  minimal/    *.mp3
  playful/    *.mp3
  dark/       *.mp3
  corporate/  *.mp3
```

The audio stage picks the folder matching the VideoSpec's `musicMood`
(any track inside; first by name) and mixes it at low volume under the
narration. No files = silent music bed (narration still works).

Good CC0 sources: freepd.com (manual download), pixabay.com/music.
Respect each track's license.
